Rather than a single disconnected image gallery, screenshots of the running Web UI are
embedded directly in the guides that describe the screen they show, so they stay next
to the explanation of what you're looking at.

You'll find screenshots in:

- [Usage → Using Shell](/maelsink/docs/usage/using-shell/) and
  [Usage → Using Composer](/maelsink/docs/usage/using-composer/) — the interactive tooling.
- [Usage → Sending Mail → Via Composer UI](/maelsink/docs/usage/sending-mail/via-composer-ui/) —
  the Composer/API Explorer/Jobs Panel screens.
- [Configuration → Web UI and API server](/maelsink/docs/configuration/web-ui-and-api-server/) —
  the main inbox and settings screens.

If you're looking for a specific screen and can't find it linked from a guide, check
[Features](/maelsink/docs/features/) for the capability it belongs to.
